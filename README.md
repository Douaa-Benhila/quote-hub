# Quote Hub

Quote Hub est une application web qui affiche une collection de **citations** célèbres. Chaque citation apparaît sur une carte avec son titre, son auteur et sa catégorie.

C'est un projet de frontend : les citations sont écrites directement dans le code, il n'y a pas de serveur ni de base de données.


## Ce que l'utilisateur peut faire

- **Lire** les citations, présentées sous forme de cartes (avec l'auteur et la catégorie)
- **Copier** une citation en un clic (bouton copier sur la carte)
- **Changer de mode** : passer du mode clair au mode sombre, et inversement (bouton lune / soleil dans la barre du haut)


## Lancer le projet

Il faut avoir [Node.js](https://nodejs.org) installé.

```bash
npm install
npm start
```

Puis ouvrir **http://localhost:4200** dans le navigateur.



## Technologies utilisées

- **Angular 21** : le framework de l'application
- **TypeScript** : le langage
- **PrimeNG 21** : les composants visuels (cartes, boutons, étiquettes)
- **PrimeIcons 7** : les icônes
- **PrimeFlex** : les classes CSS pour la mise en page
- **SCSS** : les styles
